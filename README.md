# CareerOS 🚀

CareerOS is an AI-powered SaaS platform designed to help students and developers manage their complete career journey in one place.

From DSA tracking to resume building, job applications, productivity systems, and AI career guidance - CareerOS acts like a personal career operating system.

---

## 🌟 Features

### 📊 Dashboard
- Career progress overview
- Daily streak tracking
- Productivity analytics
- Goal management

### 💻 DSA Tracker
- Track solved problems
- Topic-wise progress
- Revision planner
- Daily consistency tracking

### 📄 AI Resume Builder
- Create professional resumes
- Live preview
- ATS-friendly templates
- Download PDF support

### 🤖 AI Resume Analyzer
- Resume scoring
- Skill gap analysis
- ATS optimization suggestions
- Resume improvement recommendations

### 💼 Job Tracker
- Save jobs
- Track applications
- Interview stages
- Company-wise organization

### 🛣️ Roadmap Generator
- DevOps roadmap
- Skill learning paths
- Interactive progress tracking
- Recommended projects

### 🎤 Mock Interview Prep
- Technical interview preparation
- HR questions
- AI interview assistant
- Performance tracking

### 💡 AI Project Recommender
- Resume-worthy project ideas
- Trending tech suggestions
- Difficulty-based recommendations

### ⏳ Productivity Tools
- Pomodoro timer
- Habit tracker
- Daily planner
- Focus mode

### 🚀 Getting Started
- Clone Repository
```
git clone https://github.com/your-username/career-os.git
```
- Install Frontend
```
cd client

npm install

npm run dev
```
- Install Backend
```
cd server

npm install

npm run dev
```

### 🌐 Deployment
```
Frontend → Vercel
Backend → Render
Database → MongoDB Atlas
```
